# F010.6 — Escalate unclaimed remediations to fleet Discord

> Parent: [[F010]] closed-loop auto-remediation relay. Built 2026-06-03.

## Motivation

The 2026-06-03 incident exposed the silent-stall failure mode: a remediation was
dispatched to trail but the claim callback failed silently, so the incident sat
`open` + unclaimed with **no alert**. Worse, `unclaimedEscalations()` (relay.ts)
— which computes incidents eligible + unclaimed past `REMEDIATION_ESCALATE_MS`
(30 min) — was defined but **never called**. So if Buddy is down, no cc session
is live for the repo, or a claim fails, nobody is told.

## Scope

- **DB:** `incidents.escalation_alerted_at` (migration 0008, nullable) — dedup so
  each incident alerts at most once (mirrors `cardmem_pushed_at`).
- **`escalateUnclaimed(db, opts?)`** (incidents/escalation.ts): take
  `unclaimedEscalations(db, now)`, keep those with `escalation_alerted_at` null,
  send ONE batched fleet-Discord alert via `sendFleet(config.fleetAlertDiscordWebhook, …)`
  (exported from storm.ts), then stamp each. Stamp AFTER a successful send so a
  failed alert retries next tick instead of being swallowed.
- **Wire:** call it on the correlation tick (correlation.ts) next to
  `pushPendingToCardmem`.

### Non-goals

- No new escalation channel (reuse the existing FLEET_ALERT_DISCORD_WEBHOOK).
- No re-escalation if an incident is re-queued (one alert per incident lifetime
  is enough; keep it simple).
- cronjobs is NOT given a remediation role — it stays the dead-man + probe runner.

## Architecture

Reuses the existing pieces: `unclaimedEscalations` (eligibility + window),
`sendFleet` (the storm.ts Discord embed sender, now exported), the correlation
tick (already runs alerts/remediation/cardmem-push). Injectable `send` + `now` +
`webhookUrl` for tests.

## Acceptance criteria

See card AC. Verified: 5 unit tests (fires once / idempotent / recent-excluded /
claimed-excluded / send-failure-no-stamp), full suite 46/46, deployed; no spurious
escalation on deploy (0 open unclaimed-past-window incidents at rollout).
